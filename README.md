# Starteammate plugin for Claude Code

Connects Claude Code to your Starteammate workspace through one remote MCP server, `https://app.starteammate.com/mcp`.

Install it from the Starteammate marketplace:

```sh
claude plugin marketplace add https://starteammate.com/claude/marketplace.json
claude plugin install starteammate@starteammate
```

Then run `/mcp` in Claude Code, pick `starteammate` and choose Authenticate.
